# Whitepaper v6.3 to v6.4

Compared on 2026-10-11. The Chinese original is normative. The English file is the translation shipped with this release. v6.3 is the text this repository implemented at `0.2.0`. v6.4 is `docs/spec/whitepaper-v6.4-zh.txt` and `docs/spec/whitepaper-v6.4-en.txt` (the `.docx` files are the same documents).

Line diff of the Chinese texts: 21 hunks. Sections 1–16 other than the passages below, sections 18.1–18.5, 18.7, the body of section 19 after its opening sentence, sections 20.1–20.6, 21, 22, 24, 25.1–25.2, and sources S1–S33 are unchanged. The English translation carries the same substance. It does not add an AP2 implementation requirement that this repository acts on.

Schema release stays `1.1.0`. No schema file changed, and `freeze.json` was not regenerated. NFT order fields fit the existing `TradeEnvelope.terms` string map. Implementation version is `0.3.0`. Protocol version stays `rwaix-0.1.0`.
