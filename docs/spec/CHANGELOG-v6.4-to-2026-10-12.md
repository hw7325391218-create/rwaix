# Whitepaper v6.4 to 2026-10-12

Compared on 2026-10-12. The new Chinese text is `docs/spec/whitepaper-2026-10-12-zh.txt` (and the matching `.docx`). It supersedes `docs/spec/whitepaper-v6.4-zh.txt`. No English revision was supplied with this date. The v6.4 English file stays as the previous translation.

No schema file changed, and `freeze.json` was not regenerated.
